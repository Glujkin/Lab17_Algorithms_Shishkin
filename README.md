## Что такое алгоритм?

**Алгоритм** — это точная конечная последовательность действий, направленная на достижение определённой цели или решение конкретной задачи.

### Свойства алгоритма:
1. **Дискретность** — алгоритм состоит из отдельных шагов
2. **Детерминированность** — каждый шаг однозначно определён
3. **Конечность** — алгоритм завершается за конечное число шагов
4. **Массовость** — применим для целого класса задач
5. **Результативность** — всегда приводит к результату

---

## Что такое блок-схема?

**Блок-схема** — это графическое представление алгоритма, в котором шаги изображаются в виде блоков различных форм, соединённых стрелками.

### Основные элементы блок-схем:

| Элемент | Форма | Назначение |
|:--------|:-----:|-----------:|
| Начало/Конец | Овал | Начало или завершение алгоритма |
| Процесс | Прямоугольник | Выполнение действия |
| Решение | Ромб | Условие (да/нет) |
| Ввод/Вывод | Параллелограмм | Ввод данных или вывод результата |
| Стрелка | Линия со стрелкой | Направление выполнения |
